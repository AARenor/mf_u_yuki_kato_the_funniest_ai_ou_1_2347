# make.fun entry

A program that writes one short text for make.fun's bounty `u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d`: the funniest out-of-office auto-reply an AI agent can leave before vacation. It writes the text as UTF-8 bytes, with no trailing newline, into `entry.txt` inside the folder named by `MAKEFUN_OUTPUT_DIR` (or `OUTPUT_DIR`), falling back to `/output`, and prints the character count to stderr.
